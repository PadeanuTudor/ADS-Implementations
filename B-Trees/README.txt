How to use:


- Download the B-Tree folder and open it in your Java IDE of choice
- Run it
- After choosing the degree of the B-Tree, an self-explanatory menu should show.

- 1 to add a number in a B-Tree, after typing 1 the program will ask you which number you want to add in
- 2 to remove a number from said B-Tree, after typing 2 the program will ask which number you want to remove from the tree
- 3 to traverse the B-Tree, it will list all the numbers in the tree in-order
- 0 closes the program
- entering anything else will go back to the menu


Important:
- The tree is empty by default, and it doesn't save it in-between runs
