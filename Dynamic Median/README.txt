How to use:


- Download the Dynamic Median folder and open it in your Java IDE of choice
- Run it
- In the terminal, an self-explanatory menu should show.

- 1 to add a number in a Red-Black tree, after typing 1 the program will ask you which number you want to add in
- 2 to remove a number from said Red-Black tree mentioned above, after typing 2 the program will ask which number you want to remove from the tree, if you type a number that's not in the Red-Black tree then it'll just loop back to the menu
- 3 to show the median, it tells you the median
- 0 closes the program
- entering anything else will go back to the menu


Important:
- The tree is empty by default, and it doesn't save it in-between runs
