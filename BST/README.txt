How to use:


- Download the BTS folder and open it in your Java IDE of choice
- Run it
- In the terminal, an self-explanatory menu should show.

- 1 to add a number into the tree, the program will ask you for a number, add it to the tree then go back to the menu
- 2 to remove a number from the tree, the program will ask you for a number, remove it from the tree, then go back to the menu
- 3 to search if a number is inside the tree, the program will ask for a number then say if it's in the tree or not.
- 4 tells you the minimum value in the tree
- 5 tells you the maximum value in the tree
- 0 closes the program
- entering anything else will go back to the menu


Important:
- The tree is empty by default, and it doesn't save it in-between runs
- Picking option 4 and 5 (Finding Min/Max) when the tree is empty will throw an "Empty Tree" exception and close the program
